# Frontend Instructions

## Scope

This directory contains the React/Vite frontend for the Product Discovery Agent.

For frontend tasks:

- Work only inside `frontend/`.
- Do not inspect or modify the Python backend unless explicitly requested.
- Do not modify `main.py`, `api.py`, `analysis/`, `rag/`, `report/`, or backend tests.
- Preserve the existing `/discover` API contract.

## UI

- Monochrome black/white/neutral-gray design.
- No purple.
- No gradients.
- No unnecessary colors.
- Editorial, premium, minimal aesthetic.
- Large typography.
- Generous whitespace.
- Thin borders.
- Strong visual hierarchy.
- Avoid generic AI-dashboard styling.

## Code

- Prefer existing dependencies.
- Avoid unnecessary packages.
- Keep components maintainable.
- Do not refactor unrelated code.
- Run lint/build after UI changes.
